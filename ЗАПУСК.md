# Как запустить INDUSTRIA TWIN

Пошаговая инструкция для запуска на своём компьютере (macOS, Linux или Windows).

## 1. Что нужно установить

* **Node.js 20.9 или новее** (вместе с ним ставится npm) — <https://nodejs.org>
* **Git** — чтобы скачать проект
* Интернет при первой установке (скачиваются зависимости и шрифты)

Проверить версии:

```bash
node -v
```

```bash
npm -v
```

## 2. Скачать проект

```bash
git clone https://github.com/abramovllmakk/GAZPROM-HAC.git
```

```bash
cd GAZPROM-HAC
```

## 3. Установить зависимости

```bash
npm install
```

## 4. Создать файл настроек `.env`

macOS / Linux:

```bash
cp .env.example .env
```

Windows (PowerShell):

```powershell
Copy-Item .env.example .env
```

Откройте `.env` и замените значение `SESSION_SECRET` на любую случайную строку **не короче 32 символов**. Сгенерировать её можно так:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

## 5. Создать базу данных и демонстрационные данные

```bash
npm run setup
```

Команда создаёт SQLite-базу `prisma/dev.db`, применяет миграции и заполняет её: пользователи, участки цеха и шесть рассчитанных сценариев. Это занимает до минуты.

## 6. Запустить

Рабочий режим (быстрее работает):

```bash
npm run build
```

```bash
npm start
```

Или режим разработки (с автообновлением при правке кода):

```bash
npm run dev
```

Откройте в браузере: **<http://localhost:3000>**

## 7. Войти

Логины и пароли демонстрационных учётных записей (администратор, инженер, наблюдатель) — в [README.md](README.md#демонстрационные-учётные-записи). Свои пароли можно задать в `.env` переменными `DEMO_ADMIN_PASSWORD`, `DEMO_ENGINEER_PASSWORD`, `DEMO_VIEWER_PASSWORD` до шага 5 (или потом выполнить `npm run db:seed`).

## Что где смотреть

| Раздел | Что внутри |
|---|---|
| Обзор производства | KPI, загрузка участков, узкое место |
| Процесс | мнемосхема потока изделий |
| Сценарии / Сравнение | расчёт «что если» и сравнение «до/после» |
| 3D-тур | детальная 3D-модель цеха (сверху страницы) и сцена с воспроизведением рассчитанного прогона |

3D-сцене нужен браузер с WebGL (Chrome, Edge, Firefox, Safari последних версий). Без WebGL показывается 2D-план цеха.

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| `Port 3000 is already in use` | Закрыть другое приложение на порту 3000 или запустить на другом: `npm start -- -p 3001` |
| Ошибка про `SESSION_SECRET` | Проверить, что `.env` создан и строка не короче 32 символов |
| Пустые страницы или ошибка базы | Пересоздать данные: `npm run db:reset`, затем `npm run setup` |
| Не скачивается шрифт при сборке | Проверить интернет и повторить `npm run build` |
| Старая версия Node.js | Обновить Node.js до 20.9+ |

## Проверка проекта (необязательно)

```bash
npm run verify
```

Запускает линтер, проверку типов, все тесты и сборку.

> Все производственные данные в системе синтетические и служат только для демонстрации.
